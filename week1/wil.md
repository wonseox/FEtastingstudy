vs code와 git hub의 연동하는 법에 대해 알게되었다.
처음에는 가이드라인을 보고 commit과 저장하는 법 그리고 수정하는 법과 전후차이를 보여주는 양식조차 읽기 힘들어서 계속 오류가 뜬 줄 알았다.
코드의 의미를 하나하나 다 알고 가는 것이 아닌 직접 해보는 위주로 가서 재밌었다.
간단하게나마 html은 무엇이 있는지, css는 어떻게 보이는지, js는 어떻게 동작하는지 다룬다는 것을 알게되었다. 또한 dom을 통해 위치를 찾으며 사용자가 실행한 것을 사건으로 받아들인다는 것도 알게되었다.
당연시여겼던 것들 뒤에는 자연스럽게 만들기 위한 개발자의 노고가 있었음이 신기했고 평소에 자연스레 여겼던 것들이 수업 직후에는 부자연스럽게 느껴졌다.
markdown 문법에 대해 약간 읽어봤는데 github에서 repository, 즉 우리가 과제를 낼때 사용하는 저장소가 쓰는 문법인 것 같다. 감이 잘 안 잡힌다.
실제로 음악 웹사이트를 만들어보고 간단하게나마 내가 원하는 노래를 넣고 제목이랑 가수를 설정하니 재밌었다.
